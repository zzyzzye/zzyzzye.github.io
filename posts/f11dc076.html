Java的集合框架知识点

发表于2024-09-06|更新于2024-09-06|Java
|字数总计:1.1k|阅读时长:3分钟|阅读量:

Java 的集合框架是用于存储和操作多个元素的类和接口的集合，它提供了一种高效的方式来处理数据。以下是对 Java
集合框架的详细总结，包括其结构、主要接口、常用实现类、使用场景以及一些常见操作。

一、 集合框架概述

① 集合框架：

Java 集合框架是一个数据结构库，用于管理和处理多个数据对象。

② 根接口：

Collection 是所有集合类的根接口，提供了一组通用的方法来处理集合。


二、主要接口-Collection 接口

① 定义：

作为集合框架的根接口，所有集合类（如 List、Set 和 Queue）都直接或间接实现这个接口。

② 特点：

  1. 它代表一组元素的集合，提供了一些通用的操作方法，比如添加、移除、检查元素、遍历等。

  2. 不包含任何与元素顺序、重复性或者访问特性相关的方法。

1、常用方法：

方法名 解释
add(E e)： 添加元素到集合。
remove(Object o)： 从集合中移除元素。
size()： 返回集合的大小。
isEmpty()： 判断集合是否为空。
contains(Object o)： 检查集合是否包含指定元素。
clear()： 清空集合。

三、主要接口-List 接口

① 定义：

List 是 Collection 的一个子接口，表示一个有序的集合，允许重复元素。

② 特点：

保持插入顺序，用户可以通过索引访问元素。
允许重复的元素，例如可以添加两个相同的元素。

③ 常用实现：

  1. ArrayList：基于动态数组实现，适合随机访问。

  2. LinkedList：基于双向链表实现，适合频繁的插入和删除操作。

四、主要接口-Set 接口

①定义：

Set 是 Collection 的另一个子接口，表示一个不允许重复元素的集合。

②特点：

不保证元素的顺序（但某些实现类如 LinkedHashSet 可以保持插入顺序）。

不允许包含重复元素，如果添加一个已经存在的元素，集合将保持不变。

③常用实现类

  1. HashSet: 基于哈希表实现，提供快速的查找和添加操作，不保证顺序。

  2. LinkedHashSet: 结合了 HashSet 的性能和元素插入顺序的保持。

  3. TreeSet: 基于红黑树实现，根据元素的自然顺序或指定的比较器进行排序，并且不允许重复元素。

④使用场景：

需要确保元素唯一性时，使用 Set。

五、区别总结

特性 Collection List Set
允许重复 是 是（允许重复元素） 否（不允许重复元素）
有序性 不保证 是（保持插入顺序） 否（不保证顺序；TreeSet 有序）
随机访问 不支持 支持（通过索引访问） 不支持（无索引访问）
主要实现在 - ArrayList, LinkedList HashSet, LinkedHashSet, TreeSet

六、主要接口-Queue 接口

①定义：

表示用于存储等待处理的元素，通常表现为先进先出（FIFO）。

②常用实现：

LinkedList：实现了 Queue 接口，可用作队列。

PriorityQueue：根据元素优先级进行处理。

③使用场景：

需要按照特定顺序（如 FIFO）处理元素时，使用 Queue。

七、5. 总结与最佳实践

  1. 选择合适的集合类型：根据需求选择合适的集合类型，例如需要按序存储用 List，需要唯一性用 Set，需要队列行为用 Queue。

  2. 关注性能：不同集合实现的性能特征不同，要根据操作类型（如插入、查找、删除）选择最优的实现。

  3. 使用泛型：确保类型安全，避免类型转换异常，建议使用泛型（如 List）。
