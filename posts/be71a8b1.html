一、匿名实现

在 Java 中，匿名实现（Anonymous Implementation）指的是在没有命名的情况下直接实现一个接口或继承一个类的一个实例。这种方式通常用于需要一次性使用的场合，不必为每个实现创建一个单独的类。

匿名实现的特征

1.无名称：

匿名实现没有类名，因此你不能在其他地方引用它，只能在它被创建的上下文中使用。

2.直接在实例化时实现接口或继承类：

你可以在创建对象的同时直接实现方法。这通常用于接口或抽象类。

3.简化代码：

通过不为每个实现创建一个单独的类，能够减少代码量，特别是在你只需要实现一次的情况下。

④泛型接口

泛型接口是 Java 中一种强大的特性，允许开发者在定义接口时指定一个或多个类型参数。泛型接口使得代码更具复用性和类型安全。可以定义并实现泛型接口，同时对多个类型进行操作。 使用泛型接口时，能避免显式的类型转换，有助于减少运行时错误。

  • 定义泛型接口：
    泛型接口的定义类似于普通接口，只是在接口名称后面添加类型参数。例如，<T> 表示该接口是一个泛型接口，T 是类型参数，使用时可以替换为具体类型。

  • 使用多个类型参数：
    可以定义多个类型参数，使用逗号分隔。例如：<T, U>。

  • 实现泛型接口：
    当实现泛型接口时，需要指定具体类型或继续使用类型参数。

  • 类型擦除：
    在编译时，泛型信息会被擦除，编译器用原始类型替代类型参数。因此，泛型接口不能创建泛型数组或使用基本数据类型。

  • 类型安全：
    泛型接口能够提供编译时类型检查，减少运行时类型转换错误。

3.泛型的优点

类型安全性:

泛型提供了编译时的类型检查，避免在运行时发生类型转换错误。例如，如果你定义了 Comparator，编译器能够确保你只比较
Integer 对象。

代码重用性:

通过使用泛型，可以编写更通用的代码。例如，使用 Box 类，可以轻松创建不同类型的盒子，而不需要为每种类型编写不同的类。

5.问题抛出:

我为什么这样写会报错?

因为在 Java 中，不能直接使用原始数据类型（如 int、char 等）来定义泛型集合（如 List、ArrayList 等）。 这主要是因为
Java 的泛型只支持引用类型（对象类型），而原始数据类型是基本类型。

①原始类型与引用类型的区别

  • 原始类型（Primitive Types）：
    Java 有八种原始数据类型：int、char、double、boolean、byte、short、long、float。
  • 引用类型（Reference Types）：
    这些是对象类型，所有非基本类型（如 String、对象、数组等）都属于这一类。

②泛型只能使用引用类型

Java 的泛型设计要求使用对象类型，而不是基本类型。这是因为泛型是为了提供类型安全的对象集合，且与运行时的动态类型检查无关。
